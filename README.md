# CineBook — Movie Ticket Booking System

CineBook is a terminal-based movie ticket booking application built as a Java OOP and MySQL DBMS project. It uses JDBC to read and update data in MySQL.

## Features

- Browse movies and show timings
- View availability on a 5-row by 8-seat map
- Book multiple seats with transaction-based validation
- Apply the `CINE10` coupon for 10% off
- Cancel bookings and calculate an 80% refund
- View booking history, revenue, and seat occupancy reports
- Use administrator options to manage movies and show timings

## Project files

- `CineApp.java` — application, menu, database, and model classes in one source file
- `schema.sql` — database schema, sample records, seats, and optional legacy migration
- `mysql-connector-j-26.7.0.jar` — JDBC driver (or the Connector/J JAR version you downloaded)

## Requirements

- JDK 17 or newer
- MySQL Server running locally on port `3306`
- MySQL Connector/J
- MySQL Workbench or another way to run SQL scripts

## Set up the database

1. Open `schema.sql` in MySQL Workbench.
2. Run the main schema and sample-data statements.
3. Confirm that the `cinebook` database contains the `movie`, `shows`, `seat`, `booking`, and `booking_seat` tables.

The script creates three sample movies and shows, with 40 seats for each show.

### Upgrading an older CineBook database

Back up the database before migrating. The old booking structure is not changed by `CREATE TABLE IF NOT EXISTS`.

1. Run the main setup section of `schema.sql`.
2. At the end of `schema.sql`, follow the instructions in **OPTIONAL LEGACY MIGRATION** and run those statements once.
3. The migration renames and retains the original booking tables as `booking_before_migration` and `booking_seat_before_migration`, then copies the booking data to the new tables.

Do not run the migration section again after it has succeeded. Do not drop the database to upgrade it.

## Configure the MySQL login

The nested `DBConnection` class in `CineApp.java` defaults to:

- User: `root`
- Password: `2504`
- URL: `jdbc:mysql://localhost:3306/cinebook`

If your MySQL account uses different settings, update the `URL`, `USER`, and `PASSWORD` values in that class.

## Compile and run on Windows

Open Command Prompt or PowerShell in the project folder. Use the actual Connector/J JAR filename if it differs.

```powershell
javac -cp ".;mysql-connector-j-26.7.0.jar" CineApp.java
java -cp ".;mysql-connector-j-26.7.0.jar" CineApp
```

## Use the application

### Customer

1. Select **Customer** from the main menu.
2. View movies, show timings, or seat availability.
3. Choose a show ID to view its seats or book tickets.
4. Enter seat codes separated by commas, such as `C3,C4`.
5. Enter `CINE10` for the discount, or press Enter to skip.
6. To cancel, choose the cancellation option and provide the show ID and booking ID.

## Notes

- A booking validates all selected seats before updating them. Database transactions prevent partial bookings.
- Booking IDs are generated by MySQL.
- Cancelling a booking marks it `CANCELLED` and makes its seats available again.
- Revenue reports exclude cancelled bookings.
- This is a console-based college project, not a production booking or payment system.

## Troubleshooting

- **Access denied:** Check the MySQL username and password in `CineApp.java`.
- **Unknown database `cinebook`:** Run the main setup section of `schema.sql`.
- **No suitable driver:** Ensure the Connector/J JAR filename in the commands matches the JAR in the project folder.
- **Communications link failure:** Ensure MySQL Server is running and listening on port `3306`.
- **Missing booking columns after an upgrade:** Back up the database and follow the one-time legacy migration instructions in `schema.sql`.
